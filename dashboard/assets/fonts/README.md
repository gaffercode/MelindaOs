# Fonts for official RSIA Melinda PDF letterhead

Studio/STARKES PDF builders embed Calibri (metric-compatible with Carlito used on official RSIA Melinda surat) so output matches the hospital letterhead.

Place these files locally (not redistributed via public npm):

- `Calibri-Regular.ttf`
- `Calibri-Bold.ttf`
- `Calibri-Italic.ttf`

If missing, builders fall back to Helvetica (layout/kop/logo tetap sama).
