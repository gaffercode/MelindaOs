# Docs

Human documentation for MelindaOS. Hospital knowledge lives in the numbered folders under `knowledge/`, not here.

| Folder | What it holds |
|---|---|
| [`architecture/`](architecture/) | System architecture and decision records. |
| [`contracts/`](contracts/) | Contracts: Executive Office. |
| [`guides/`](guides/) | Studio publication. |
| [`engineering/`](engineering/) | Development setup, testing and verification. |
| [`operations/`](operations/) | Deployment, topology, runbook, observability, troubleshooting, the Director's signature list, and notes on single-source data sets ([`operations/ssot/`](operations/ssot/)). |
| [`security/`](security/) | Security and regulatory safety. |
| [`governance/`](governance/) | Repository boundaries. |
| [`data/`](data/), [`integrations/`](integrations/), [`product/`](product/) | Data model, integrations, product scope. |
| [`reviews/`](reviews/) | Audits, tech debt, feature ideas. |
| [`plans/`](plans/), [`superpowers/`](superpowers/) | Dated plans and specs. Historical; not updated after the work lands. |
| [`handoff-archive/`](handoff-archive/) | Older `HANDOFF.md` entries. |

`documentation.manifest.json` maps each documentation category to its document and evidence.
