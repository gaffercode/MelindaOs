# 90-Day Rollout

## Hari 0–14 — Governance & Foundation
- Grok Bot Enterprise/security review.
- Tetapkan 5 trust domains dan designated owners.
- Deploy Vault/secret manager + MAAF backend staging.
- Deploy custom MCP staging; hanya tools L0.
- Setup official channel registry + one-time OAuth.
- Baseline KPI: jumlah login manual, open loops, claim aging, reconciliation variance, complaint SLA.

**Exit gate:** tidak ada raw secret di Bot/n8n; audit trail aktif; ATLAS dan GUARDIAN L0 stable.

## Hari 15–30 — Executive & Public Automation
- ATLAS Morning Brief.
- Token Health + auto-recovery.
- Social calendar draft/adaptation/scheduling.
- Website/email integration.
- L3 publishing hanya approved content class dan reversible correction process.

**Target:** routine manual login mendekati nol; Direktur hanya menerima auth exception yang benar-benar human-required.

## Hari 31–60 — Operations / HR / Finance
- FLOW, OPS, PEOPLE, LEDGER read-only → L2 internal workflows.
- CLAIMS deficiency chase.
- NEXUS RME completeness/lab/pharmacy exception feeds.
- Weekly GUARDIAN audit.

**Target:** >=60% open-loop follow-up selesai tanpa Direktur menjadi router.

## Hari 61–90 — Cross-Agent Orchestration
- Handoff lintas domain.
- Claim-to-RME resolution loop.
- Staffing-to-capacity loop.
- External publish policy automation.
- Evaluate Temporal only for workflows that demonstrated durability need.

**Production review:** precision alerts, human override rate, policy denials, credential incidents, manual interventions, time saved, financial/operational KPI changes.
