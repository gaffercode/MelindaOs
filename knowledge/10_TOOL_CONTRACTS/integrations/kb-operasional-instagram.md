# Instagram Automation

**Primary path:** Instagram API untuk akun profesional; content publishing/insights/moderation sesuai permission yang diberikan.

MAAF menyimpan hanya secret reference di registry. Long-lived token direfresh sebelum expiry selama masih valid. Re-consent/2FA/CAPTCHA yang dipaksa Meta menjadi exception tunggal, bukan workflow harian.

Konten klinis/edukasi medis harus melewati LEG/GUARD bila mengandung klaim yang dapat memengaruhi keputusan kesehatan.
