# SOURCE PRIORITY

Urutan sumber saat terjadi konflik:

1. **Live authoritative system/tool** untuk status dinamis.
2. **Official regulatory source yang paling baru** untuk hukum/perizinan.
3. **Approved canonical Melinda knowledge**.
4. **Operational playbook/policy** sesuai scope.
5. **Historical/quarantined/archive** hanya untuk konteks, bukan keputusan aktif.

Jika dua sumber canonical bertentangan dan freshness tidak dapat ditentukan, eskalasi daripada mengarang resolusi.
