# Live Data Requirements

To operationalize this knowledge, Melinda should have read access to the following authoritative data, preferably through `melinda-hospital-mcp`.

## Hospital capability

- current services and subservices;
- current doctors and specialties;
- clinical service competency map;
- diagnostic/therapeutic capability;
- operating room availability where relevant;
- emergency capability;
- inpatient capacity;
- referral acceptance status.

## JKN/BPJS

- current cooperation status by service;
- participant eligibility;
- registered FKTP where permitted;
- referral status/destination/specialty;
- control letter status;
- SEP eligibility;
- current referral mapping to RSIA Melinda.

## Private payer

- insurer/corporate network;
- guarantee method;
- preauthorization requirement;
- referral requirement;
- contact/escalation channel.

## Operations

- doctor schedules;
- appointment slots;
- online registration cutoff;
- queue;
- tariff/estimate;
- front-office contact;
- referral desk contact;
- emergency contact;
- bed status.

## Mandatory source-of-truth rule

The agent must not substitute public web data for a live internal transaction source when the latter exists.
